# Prompt recipes

Copy and adapt these prompts. Replace `example.org` and bracketed fields.

## Homepage

> Use event-audience-coverage to audit https://example.org. This is a [type of Drupal event]. Identify the main audience promises, score relevant personas using observed evidence, and propose five high-impact homepage changes. Explain which audiences are not applicable.

## Session or speaker page

> Audit this session page: [URL]. Focus on the intended experience level, learning outcomes, prerequisite clarity, role relevance, and next action. Do not penalise a specialist session for not targeting all personas.

## Draft before publication

> Using event-audience-coverage, review the pasted draft for a [DrupalCamp/meetup/conference] announcement. Identify intended personas, unclear language, and missing value propositions. Suggest revised wording while preserving the author's voice. Do not claim the draft has been published.

## Full sitemap

> Audit [sitemap URL]. List discovered, inspected, and unverified pages. Classify page types and deliver a persona × page matrix with evidence, ten prioritised improvements, and a CSV-ready export. Mark unvisited pages as unverified.

## Contribution day

> Review [URL] as a Drupal contribution day page. Assess whether first-time contributors, non-code contributors, and experienced maintainers understand prerequisites, tasks, mentoring, logistics, and next steps.

## Re-audit

> Compare the attached earlier audience audit with a new audit of [URLs]. Hold the page scope and scoring rules constant where possible. Distinguish genuine content changes from inaccessible pages and changed coverage.
