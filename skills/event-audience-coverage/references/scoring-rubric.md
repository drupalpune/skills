# Scoring rubric

Score relevance/coverage for each persona **given the page's purpose**:

| Score | Label | Criteria |
|---|---|---|
| 0 | Missing | Reasonably in-scope persona has no discernible relevant message or path |
| 1 | Implicit | Relevance is inferred; no explicit value or next action |
| 2 | Partial | Persona/topic visible but benefit, evidence or action incomplete |
| 3 | Good | Clear value and meaningful route/action, with some credible support |
| 4 | Strong | Explicit benefit, evidence/example, and clear relevant next action |
| N/A | Out of scope | Persona not reasonably expected on this purpose-specific page |
| ? | Unverified | Content insufficient or inaccessible; no defensible score |

Document per evaluated cell: score, page URL/section, short supporting quote or heading, short rationale, confidence (High/Medium/Low). Only assign high confidence with direct evidence. Do not use `0` for inaccessible pages.

## Distinctions
- Keyword presence alone does not earn 3/4.
- Implicit mentions do not equal welcome/inclusion.
- A technical session page can mark nontechnical buyers N/A; homepage and Why Attend should generally have broad coverage, unless event scope establishes otherwise.
- Determine primary audience from real page purpose, not assumed conference branding.
- An audience covered on another page may improve **site** coverage, not necessarily the current page.

## Site-level rollup
For each persona report: relevant pages inspected, best evidence-backed score, effective conversion path, gaps, and confidence. Do not blindly average N/A or ? scores. Optionally calculate percent of relevant evaluated pages scoring >=3, with numerator/denominator disclosed. Avoid falsely precise site-wide scores for partial crawls.

## Priorities
- **P0:** critical misunderstanding, inaccessible essential path, or severe exclusion on key entry/conversion pages.
- **P1:** material missing/weak audience path on a key page, or recurring site-wide gap.
- **P2:** helpful clarification, supporting example, contextual link, or editorial refinement.

For each recommendation, give target persona, concrete location, proposed change, rationale, effort S/M/L and priority.
