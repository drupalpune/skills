# Page types and appropriate expectations

| Type | Typical broad audiences | Key audit questions |
|---|---|---|
| Homepage / event overview | Broad, cross-sector | Can visitor quickly identify event purpose, dates, who benefits, routes to program and tickets? |
| Why Attend / audience overview | Broad, cross-sector | Are learner, practitioner, buyer, seller, AI/product, and community outcomes represented? |
| AI Summit / theme | AI builders/adopters, business, product, public sector, researchers | Are concrete use cases and applicability beyond Drupal apparent? |
| Conference / Drupal track | Developers, architects, design/content, business adopters, agencies | Are both technical and practical adoption stories clear? |
| Contribution / Sprint / Hackathon | Contributors, students, engineers, designers, product teams | Are first-timers welcomed and logistics/prerequisites clear? |
| Program / Sessions / Agenda | All relevant, discoverable by role/intent | Can visitors find matching content and distinguish difficulty and outcomes? |
| Individual session | Intended specialty, adjacent interested users | Is primary audience, takeaway and prerequisite clear? Don't force every persona. |
| Speakers | Audience interested in expertise | Is speaker credibility, relevance and topic understandable? |
| Tickets / Registration | All prospective attendees | Are ticket choices, inclusions, pricing, prerequisites, links and accessibility clear? |
| Sponsor / Exhibit / Partner | Vendors, agencies, partners, decision makers | Are audience fit, offerings, outcomes and contact pathways concrete? |
| Travel / Stay / Visitor guide | Domestic, international, newcomers | Are location, transport, visa and stay details clear and verified? |
| Blog / Announcement / Social draft | Selected target audiences | Does the targeted message make sense? Is CTA aligned? |
| About / Organisers / Community | Cross-community, potential supporters | Is host identity, credibility, inclusivity and participation visible? |

Classify unknown pages by actual purpose. Site-wide breadth should emerge from multiple targeted pages, not every page doing everything.
