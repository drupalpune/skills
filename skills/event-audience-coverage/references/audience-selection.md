# Audience selection and applicability

1. Read explicit purpose and target attendees from actual source content; distinguish this from inference.
2. Select primary, secondary, incidental, and out-of-scope personas using `personas.md` and `event-types.md`.
3. For each page/persona intersection, record one of: Expected, Relevant-but-optional, Not applicable, or Unverified applicability.
4. Use N/A only for genuinely out-of-scope personas. Do not mark inaccessible pages as 0; use `?`.
5. A missing audience is a gap only if the event or page should credibly serve them. Do not force investor or procurement messaging onto a technical meetup.
6. Cross-cutting visitor needs (clear time/place, access information, costs, next action) are assessed independently of persona.
7. Evidence provenance: exact URL or supplied content excerpt, section/heading, retrieval status and audit date. Do not fabricate quotes or links.
8. For website-wide reporting, do not give every page equal weight by default. Show qualitative prominence (homepage, conversion, detail) and describe any weighting.
9. Report separately: coverage of expected audiences, evidence confidence, crawl/audit completeness, and visitor-journey completeness. Never collapse them into an unjustified overall score.
