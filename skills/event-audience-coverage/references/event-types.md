# Event types and evaluation context
Determine event type from supplied information before selecting audiences. Never assume DrupalCon-scale coverage for a meetup.

| Event type | Typical emphasis | Critical content checks |
| --- | --- | --- |
| DrupalCon / major conference | Multi-role technical, business, community participation | Role-specific routes, accessibility, program discovery, ticket/venue clarity |
| DrupalCamp / regional conference | Regional practitioners, learners, agencies, local community | Beginner pathways, local accessibility, session levels, networking |
| Local meetup | Participants interested in a narrow topic or community | Topic clarity, date/time/location, prerequisites, newcomer welcome |
| Contribution day / sprint | Contributors and prospective contributors | First-timer onboarding, issue selection, mentorship, tooling, non-code participation |
| Workshop / training | Learners at a defined level | Prerequisites, outcomes, materials, capacity, accessibility |
| AI / cross-disciplinary summit | AI and digital technology adopters and builders | Non-Drupal relevance, practical use cases, role-specific value |
| Virtual / hybrid gathering | Remote participants | Time zones, access instructions, recordings policy, remote participation |

Multiple labels may apply. Use the most specific event type plus relevant secondary labels. A small event may target one narrow audience successfully. If type is unknown, report that and avoid definitive coverage penalties.
