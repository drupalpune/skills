# How to audit one page

Use this when checking a homepage, program page, session description, sponsor page, or unpublished draft.

## Steps

1. Provide a public page URL, or paste the page content if the URL is unavailable.
2. State the event type and intended readers if known. If unknown, ask the skill to infer cautiously from available evidence.
3. Request a persona-by-page assessment with 0–4, `N/A`, and `?` (unverified) scores.
4. Ask for exact evidence (section names, short excerpts, URLs) and recommendations tied to those findings.
5. Review suggested copy with the organising team before publishing.

## Example prompt

> Use event-audience-coverage to audit https://example.org/why-attend. This is a regional DrupalCamp. Identify primary and secondary audiences, score relevant personas, cite observed content, mark inaccessible content as unverified, and give five actionable edits with exact placement and sample wording.

## Expected results

- Page purpose, intended audiences, and access limitations
- Coverage matrix with evidence and confidence
- Missing or unclear value propositions and next steps
- Prioritised edits, **not** automatic publication

A niche technical session is not expected to speak to every possible persona. `N/A` is valid when justified.
